# DNA Sequence Analyzer 🧬

A beginner-friendly Python bioinformatics project
for analyzing DNA sequences.

## Features
- DNA sequence validation
- Sequence length calculation
- Nucleotide counting (A, T, G, C)
- GC content calculation
- Complement sequence
- Reverse complement
- FASTA file support
- Sequence comparison
- Data visualization
- Automated unit testing

## Technologies Used
- Python
- Matplotlib
- Unittest

## How to Run

1. Install required libraries:
   pip install matplotlib

2. Run the analyzer:
   python dna_analyzer7.py

3. Run automated tests:
   python -m unittest -v test_dna_analyzer.py
